# Architecture Decision Records

Use ADRs to record important product, architecture, safety, and operational decisions.

## Format

Each ADR should include:

- Status: proposed, accepted, superseded, or rejected.
- Context.
- Decision.
- Consequences.

## Naming

Use sequential files:

```text
0001-short-decision-title.md
0002-next-decision.md
```

Do not rewrite accepted ADR history. Add a new ADR that supersedes an older one when the decision changes.
